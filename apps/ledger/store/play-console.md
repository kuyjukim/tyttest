# Play Console — 콘솔에 직접 입력해야 하는 답변

저장소에 둘 수 없고 콘솔 폼에만 존재하는 항목들입니다. 틀리게 답하면
실수가 아니라 **정책 위반**으로 처리되므로, 답과 그 근거를 여기에 적어
둡니다.

## 데이터 보안 (Data safety)

| 질문 | 답 | 근거 |
| --- | --- | --- |
| 앱이 사용자 데이터를 수집하거나 공유합니까? | **아니요** | 앱에 네트워크 코드가 없습니다. `apps/ledger/lib` 어디에도 HTTP 클라이언트, 소켓, 플러그인 채널을 통한 전송이 없습니다. |
| 전송 중 암호화 | 해당 없음 | 전송 자체가 없습니다. |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | **예** | 앱 안에서: 설정 → 전부 삭제. 서버 사본이 없으므로 요청할 곳이 따로 없습니다. |
| 광고 ID 사용 | 아니요 | 광고 SDK가 없습니다. |
| 금융 정보 수집 | 아니요 | 사용자가 입력한 금액은 기기를 떠나지 않습니다. **"수집"은 앱 밖으로 나가는 것을 뜻하므로, 앱 안에 머무는 금액은 수집이 아닙니다.** 이 칸을 "예"로 답하면 쓰지도 않는 데이터 유형을 선언하게 됩니다. |

> OS 백업(Google 자동 백업)은 이 양식에서 선언 대상이 아닙니다. 양식이 묻는
> 것은 **앱이** 수집·공유하는 것이고, 백업은 운영체제가 사용자 본인의 Google
> 계정으로 가져가는 것입니다. 다만 개인정보 처리방침에는 명시해 두었습니다.

## 콘텐츠 등급 설문 (Content rating)

유틸리티/생산성으로 분류하고, 폭력·성적 콘텐츠·욕설·약물·도박·공포 항목에
모두 **아니요**. 사용자 간 상호작용 없음, 위치 공유 없음, 디지털 구매 없음
(앱 자체가 유료이고 인앱 구매가 없습니다). 결과는 전 연령가가 됩니다.

## 광고

**아니요.** 앱에 광고가 없습니다.

## 타겟층 및 콘텐츠

13세 이상. 아동을 대상으로 하지 않으므로 Families 정책 대상이 아닙니다.

## 개인정보 처리방침 URL

`store/privacy-policy.md`를 공개된 주소에 올리고 그 URL을 넣습니다. 수집이
없어도 Play는 URL을 반드시 요구하며, "수집하지 않습니다"라는 텍스트 답변을
URL 대신 받아 주지 않습니다. 올리기 전에 `{{DEVELOPER}}`와
`{{CONTACT_EMAIL}}`을 채우세요.

## 가격과 국가

- 유료 선결제. **₩8,000 / $5.99** (근거는 `RELEASE.md`의 Pricing).
- 한국을 포함해 판매할 국가를 고릅니다. Play는 국가별 가격을 자동 환산해
  주지만, 환산값이 그 나라에서 어색한 숫자(예: ¥903)로 떨어지는 경우가
  많으니 주요 국가는 손으로 다듬는 편이 낫습니다.
- **유료 앱은 출시 후 무료로 바꿀 수 있지만, 무료 앱은 유료로 바꿀 수
  없습니다.** 순서를 되돌릴 수 없으니 유료로 시작합니다.

## 출시 전에 걸리는 시간

신규 **개인** 개발자 계정은 프로덕션 접근을 신청하기 전에 비공개 테스트를
테스터 12명 이상, 14일 연속으로 돌려야 합니다. 법인 계정은 면제입니다.
몇 주가 걸리는 요구사항이고 정책이 자주 바뀌므로, **콘솔에서 현재 조건을
먼저 확인**하고 일정을 잡으세요. 이 요구사항 때문에 Play가 App Store보다
늦게 출시되는 것이 보통입니다.
